Conectar Google y GitHub

Las claves se guardan únicamente en este equipo. No las envíes por el chat. Crea aplicaciones OAuth de prueba con estos datos.

1 · Google

En Google Auth Platform, crea un cliente OAuth de tipo «Aplicación web». Configura el consentimiento y, si está en pruebas, añade tu correo como usuario de prueba.

http://127.0.0.1:8765/auth/google/callback

2 · GitHub

En Registrar aplicación OAuth, usa el nombre «TechStore Laboratorio» y esta página principal:

http://127.0.0.1:8765http://127.0.0.1:8765/auth/github/callback

Volver a TechStore para autorizar el acceso
